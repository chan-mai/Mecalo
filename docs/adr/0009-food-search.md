# 0009: 食品検索は読みと利用者の選択で表記揺れを吸収する

## 決定

同義語辞書は持たず、次の組み合わせで検索語と食品名の違いを吸収する。

- 形態素解析(kagome, IPA辞書)による読みでの照合
- 日本食品標準成分表の備考欄の「別名」
- 該当なしの場合の、漢字1文字ずつの読みでの再検索
- 検索結果から選んだ食品と検索語の対応付け(利用者ごと)

## 理由

- 同義語を人が列挙する方式は網羅できず、保守し続ける必要がある
- 成分表は品目名をひらがなで書く(にんじん, ぶた)ため、読みでの照合で多くの漢字表記に対応できる
- 読みも表記も異なる語(ライス→めし等)は利用者の選択から学習する

## 影響

- IPA辞書をバイナリに同梱するため、バックエンドのバイナリが大きくなる
- 読みの推定は形態素解析の結果に依存し、誤った読みになる場合がある
