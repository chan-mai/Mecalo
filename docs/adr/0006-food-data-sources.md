# 0006: 食品データの取込方針

## 決定

- 日本食品標準成分表はレポジトリに同梱せず、`mecalo import mext`実行時に文部科学省のサイトから取得する
- Open Food Factsは既定で照会しない。`MECALO_OPENFOODFACTS_LOOKUP=true`で未登録バーコードの照会を有効化でき、ダンプからの一括取込も可能
- 取込はシステム食品として保存し、内容が変わった食品のみ新リビジョンを追加する

## 理由

- 成分表の利用条件をページ上で確認できなかったため、再配布を避ける
- セルフホスト環境に外部通信を強制しない
- Open Food FactsはODbLのため、画面に出典と帰属表示を表示する
