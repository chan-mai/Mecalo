# 0005: 食事摂取基準をYAMLとしてレポジトリに置く

## 決定

日本人の食事摂取基準(2025年版)の1歳以上の値を`backend/data/dri/2025.yaml`に転記し、バイナリへ埋め込む。各値に報告書の表題とページを記載する。

## 理由

- 配布形式がPDFのみで、機械的な取込でまともな精度を出すのが難しかっtあ
- 目標算出に外部通信を必要としない
- 改訂時は新しいYAMLを追加し、出典付きで差分を確認できる

## 未対応

- 乳児(0〜11か月), 妊婦・授乳婦の付加量
- ナイアシンの耐容上限量(ニコチンアミド量で示されるため栄養値と比較できない)
