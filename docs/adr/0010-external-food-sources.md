# 0010: 外部の食品データ取得元

## 決定

- 外部取得元をバーコード照会, 外部検索, 一覧の同期の3種類のportに分け、`MECALO_SOURCES`で取得元ごとに有効化する
- 日本の外食・コンビニ・PBの栄養値は、各社公式サイトの一覧を同期してローカルの検索対象にする
- タベカルは利用者が「外部のデータも検索」を操作した場合のみ照会する
- 栄養値の保存を禁止する取得元(FatSecret, Kalori等)は採用しない
- 栄養値に基準量(`Basis`)を持たせ、重量が公表されていない「1食あたり」の値をそのまま保存する

## 理由

- 安価に使える日本の市販品・外食をJANや名前で引ける公式APIがない
- 記録はスナップショットとして保存するため、保存を禁止する取得元とは両立しない
- 外食の公表値の多くは1食あたりで重量がなく、100gあたりへ換算できない
- 公式サイトの取得はrobots.txt, 同一サイトへの間隔, 条件付きGET, 詳細ページの再取得間隔でリクエスト数を減らす
